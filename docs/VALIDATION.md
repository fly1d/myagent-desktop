# 本地验证记录

2026-10-21，Apple Silicon macOS，Swift 6.3.3 / Rust 1.98.0。

- Rust：37 个单元测试与 6 个子进程 RPC 集成测试通过。
- Swift：33 个测试通过（连接、双向工具、取消、状态恢复、草稿、验收、后台浏览器、完整后端链路和系统钥匙串）。合计 76 项；地址边界和轮次对账含参数化场景。
- Release：独立 Rust 后端与原生 Swift 应用构建通过；Info.plist 与 ad-hoc 签名结构校验通过。
- 原生界面：实际启动应用，首次配置表单、空密钥禁用状态、主窗口、编辑器与独立 SQLite 文件已检查。
- 供应商测试：使用本机 HTTP fixture 验证 SSE、分块中文、工具参数、HTTP 错误、审批后真实文件写入、命令和取消。测试密钥不进入数据库。
- 网页测试：仅用独立 WebKit、本机 fixture 验证真实非空 PNG、填写、点击、同源跳转、拒绝提交/下载、取消后恢复。
- 完整链路：生产 Swift AppModel → 真实 Rust 后端 → 本机 HTTP 模型 fixture → 原生批准 → 实际文件写入/读回 → 原生验收回执 → 退出/重启恢复。模型一侧为模拟服务，客户端、后端、文件和数据库使用生产实现。
- 钥匙串：在独立随机 QA service 中实际验证保存、更新、读取、删除；不允许系统弹窗，测试项用完清理。另验证保存失败不启用连接，后端配置失败恢复旧密钥。未读取生产账号。
- 取消/失败：审批中取消后迟到批准不写文件；用户拒绝后相同动作不再弹授权；SSE 断流/错误帧不报完成；失败及中断后历史可继续，模型切换可恢复。
- 开放问答：生产客户端与真实后端调用 ask_user，输入中文答案后实际写入/读回/验收。暂不回答返回 null/cancelled；停止后迟到答案不写文件或生成回执。回答 accept 不会代替写入审批。
- 失败恢复：HTTP 500 后显式继续与退出/重开继续都沿用原线程，保留未发送草稿，模型历史中原始用户输入只出现一次。原生协议夹具另覆盖确认前断线的两种状态：后端已记录和尚未记录；客户端核对轮次后选择继续或补发。
- 启动/停止竞态：Swift 夹具验证旧线程回复不会覆盖新线程、未确认轮次也可中断，以及恢复前等待旧轮终态。真实后端另验证同一次管道写入中的 12 对启动/立即中断，无工具请求或文件副作用，持久化终态均为 interrupted。
- 原生问答交互：独立 QA 窗口中检查空回答禁用、建议只填入、中文自由编辑、提交后立刻到达下一问题，以及关闭第二问题后返回主窗口。测试未使用生产数据和模型凭据。
- 本机无密钥：空模型名实际获取列表、自动选唯一模型、保存、执行真实写/读/验收、重开自动恢复、断开后重开仍禁用；拒绝全部操作的 CredentialStore 证明整个流程零钥匙串访问，HTTP 均无 Authorization。已有云端连接在后端不可用时切换本机测试/保存，也不读取旧密钥或遗留旧错误。
- 地址与模型边界：Swift 参数化覆盖 6 个回环允许地址与 14 个非本机/伪装/凭据地址；Rust 独立验证精确 localhost、127/8、::1，拒绝局域网、IPv6 映射与恶意域名。发现模型不启用连接；配置/执行仍拒绝空或非法模型。远端无密钥被拦时原连接仍可交付。
- 原生本机连接交互：独立 QA 应用实际操作配置窗口，空模型发现后保留成功状态，切远端无密钥禁用测试/保存，再恢复本机并保存；原生发送任务与单次批准后，报告和验收回执实际存在。模型一侧为隔离 HTTP fixture，未使用生产数据或凭据。

尚未验证：真实供应商与真实本机模型的推理任务、用户生产密钥在其具体系统授权策略下的访问、真实第三方应用 AX 操作、Developer ID 签名/公证。上述测试不能证明这些能力已完成端到端验收。
