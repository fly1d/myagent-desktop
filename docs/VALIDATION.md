# 本地验证记录

2026-10-21，Apple Silicon macOS，Swift 6.3.3 / Rust 1.98.0。

- Rust：29 个单元测试与 5 个子进程 RPC 集成测试通过。
- Swift：17 个测试通过（连接、双向工具、取消、状态恢复、草稿、验收、后台浏览器、完整后端链路和系统钥匙串）。合计 51 项。
- Release：独立 Rust 后端与原生 Swift 应用构建通过；Info.plist 与 ad-hoc 签名结构校验通过。
- 原生界面：实际启动应用，首次配置表单、空密钥禁用状态、主窗口、编辑器与独立 SQLite 文件已检查。
- 供应商测试：使用本机 HTTP fixture 验证 SSE、分块中文、工具参数、HTTP 错误、审批后真实文件写入、命令和取消。测试密钥不进入数据库。
- 网页测试：仅用独立 WebKit、本机 fixture 验证真实非空 PNG、填写、点击、同源跳转、拒绝提交/下载、取消后恢复。
- 完整链路：生产 Swift AppModel → 真实 Rust 后端 → 本机 HTTP 模型 fixture → 原生批准 → 实际文件写入/读回 → 原生验收回执 → 退出/重启恢复。模型一侧为模拟服务，客户端、后端、文件和数据库使用生产实现。
- 钥匙串：在独立随机 QA service 中实际验证保存、更新、读取、删除；不允许系统弹窗，测试项用完清理。另验证保存失败不启用连接，后端配置失败恢复旧密钥。未读取生产账号。
- 取消/失败：审批中取消后迟到批准不写文件；用户拒绝后相同动作不再弹授权；SSE 断流/错误帧不报完成；失败及中断后历史可继续，模型切换可恢复。

尚未验证：使用用户有效 API Key 的真实供应商任务、用户生产密钥在其具体系统授权策略下的访问、真实第三方应用 AX 操作、Developer ID 签名/公证。上述测试不能证明这些能力已完成端到端验收。
